# Vibe Board

轻量级看板应用 - 类 Jira 的任务管理工具

## 技术栈

- React 18 + TypeScript
- Vite
- Ant Design
- Zustand (状态管理)
- @dnd-kit (拖拽)
- react-i18next (国际化)

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview

# 代码检查
npm run lint
```

## 功能特性

- 📋 看板视图：拖拽式任务管理
- 📅 时间线视图：甘特图展示
- 🌍 国际化：中英文切换
- 🎨 主题切换：亮色/暗色模式
- 💾 本地存储：数据持久化
